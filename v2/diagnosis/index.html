Problem

WEBサイト診断で解決できる悩み

問い合わせ・予約が増えない理由がわからない

アクセスはあるのに反応がない。原因がデザインなのか、文章なのか、導線なのか、切り分けられない。

いまのHPの良し悪しを、客観的に判断できない

社内・院内に判断できる人がいない。「なんとなく古い気がする」で止まってしまっている。

制作会社の提案が妥当か、確かめる材料がない

リニューアルの見積もりをもらったが、何をどこまで直すべきかの根拠を自分でも持っておきたい。

Feature

BWSの診断の特徴

SCORE 10軸90項目で採点

検索の基本要件・言葉の一致・導線・信頼性・技術基盤・セキュリティなど10軸を、自社の採点システムによる機械計測と制作チームの目視で採点します。

REPORT 約20〜30ページの評価レポート

軸ごとの達成率と「最も大きい穴」を明記した評価レポートをお届け。検索順位・Googleマップ（MEO）・AI検索での見つかり方も実測します。

PLAN 改善方針まで提示

点数を出して終わりにしません。どこから直せば成果につながるのか、優先順位と理由つきで改善の方針までご提案します。

Flow

ご利用の流れ

01 SEND URLを送る

下のフォームにサイトのURLを入れて送信。お名前とご連絡先を添えるだけで完了します（入力は1分ほど）。

02 CHECK BWSが診断

自社の採点システムで計測できる項目を機械チェックし、表現・導線・デザインは制作チームが目視で採点します。

03 REPORT レポートをお届け

通常3〜5営業日で、約20〜30ページの評価レポートをメールでお送りします。費用はかかりません。

04 TALK 無料解説（ご希望の方）

ご希望があれば、レポートの中身と改善の進め方をオンラインで解説します。そのまま発注いただく必要はありません。

評価レポートに載るもの
  • 総合スコア（10軸90項目の達成率）
  • 軸ごとの達成状況と「最も大きい穴」
  • 検索順位・Googleマップ・AI検索での見つかり方（実測）
  • 改善の優先順位と、その理由
※画面はレポートのサンプルイメージです。数値は例であり、実際の診断結果とは異なります。

FAQ

よくある質問

Q.本当に無料ですか？

A.無料です。診断・レポート・解説まで費用はかかりません。改善を私たちにご依頼いただく場合のみ、別途お見積もりします。

Q.しつこく営業されませんか？

A.レポートをお送りして終わりです。解説やご相談はご希望いただいた場合のみ行います。

Q.どんなサイトでも診断できますか？

A.企業サイト・サービスサイト・店舗サイト・LPなど幅広く対応します。医院・クリニックのサイトも診断できます。

Q.どのくらいで結果がわかりますか？

A.URLの送信は1分ほどで完了し、レポートは通常3〜5営業日でお届けします。件数が多い時期は前後することがあります。

Q.どういう仕組みで診断していますか？

A.自社の採点システムで計測できる項目（表示速度・検索設定・セキュリティ等）を機械的にチェックし、文章・導線・デザインなどは制作チームが目視で採点します。医療系サイトの表現は、チームの歯科医師が確認します。

※診断・レポートは現状の可視化と改善方針のご提案であり、検索順位や集患・集客などの成果を保証するものではありません。 医療広告等ガイドラインに関する確認は表現面についての助言であり、適法性の保証や法律事務の提供にはあたりません。
